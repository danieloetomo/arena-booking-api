# ArenaBooking API (Docker Multi-tier)

## Deskripsi & Alasan Memilih Projek
ArenaBooking adalah API backend untuk sistem reservasi lapangan olahraga atau meja billiard. Saya memilih projek ini karena sering kesulitan mencari jadwal lapangan kosong. Projek ini sangat relevan dengan peminatan saya di bidang Backend/Cloud Engineering.

## Arsitektur
Projek ini menggunakan arsitektur multi-tier yang dijalankan sepenuhnya di dalam container Docker:
- Node.js (Express) sebagai Backend API
- PostgreSQL sebagai Database

## Cara Menjalankan Projek
1. Clone repository ini
2. Masuk ke folder
3. Salin environment
4. Jalankan Docker: `docker compose up -d --build`
5. Aplikasi bisa diakses di `http://localhost:3000`
